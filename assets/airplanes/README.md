# Airliners

Built by `tools/prepare-airplanes.mjs` from four owner-supplied airliner FBX models and two jets lifted from the owner's gate-scene FBX (SketchUp/3ds Max exports in metres). The source models carried real airline liveries and referenced logo images that were not supplied; the game repaints every plane in a fictional livery (Maple Air, Sunshore Airways, Northstar Air, Ronda Skyways, Grove Express, Rivergate Airlines) with no airline names or logos. Each GLB is one simplified, meshopt-compressed mesh with vertex colours, nose along +Z.
